# PRD: 약물 부작용 보고 서비스 (SideReport)

## 1. 제품 개요

### 비전
일반 환자와 보호자가 약봉투 사진 한 장으로 쉽게 약물 부작용을 보고하고, 축적된 데이터를 통해 미보고 부작용까지 예측할 수 있는 서비스

### 목표
- 부작용 보고의 진입 장벽을 낮춰 보고 건수를 높인다
- 사용자 데이터 축적을 통해 약물 부작용 예측 모델의 기반을 마련한다

---

## 2. 대상 사용자

| 사용자 유형 | 설명 |
|-------------|------|
| 일반 환자 | 병원/약국에서 처방받은 약을 복용 중인 성인 |
| 보호자 | 환자(어린이, 노인 등)를 대신하여 약을 관리하는 가족/보호자 |

---

## 3. 핵심 기능 (MVP)

### 3.1 약봉투 OCR 인식
- 약봉투 사진 촬영 또는 갤러리 업로드
- OCR(Azure AI Vision 또는 Google Cloud Vision)로 텍스트 추출
- 추출된 텍스트에서 약품명, 용량, 복용 횟수 파싱
- 식약처 공공 API와 대조하여 약품 정보 확인 및 보정

### 3.2 부작용 선택 보고
- 인식된 약품 목록 기반으로 많이 보고된 부작용 목록 제시 (KAERS 데이터 기반)
- 환자가 경험한 부작용 체크박스로 선택
- 직접 입력 옵션 제공 (목록에 없는 증상)
- 부작용 심각도 선택 (경미 / 보통 / 심각)
- 보고서 제출

### 3.3 내 복용약 관리
- OCR 인식 결과를 복용약 목록에 저장
- 약품별 복용 기간, 용량 관리
- 복용약 추가/수정/삭제

### 3.4 보고 이력 조회
- 제출한 부작용 보고 목록 확인
- 날짜, 약품, 증상 필터링
- 보고서 상세 조회

### 3.5 AI 분석 (알려진 부작용 여부 확인)
- 사용자가 선택한 증상이 해당 약품의 공식 부작용인지 표시
- 약물 조합(여러 약품 동시 복용) 시 주의 상호작용 안내

### 3.6 알림
- 등록한 복용약의 위험 부작용 발생 빈도 급증 시 푸시 알림
- 복용 시간 알림 (선택적)

### 3.7 의료진 공유
- 부작용 보고서를 PDF로 출력 또는 링크 공유
- 병원/약사에게 전달 가능한 형태로 제공

---

## 4. 2단계 기능 (Post-MVP)

### 4.1 부작용 예측 모델
- 축적된 사용자 부작용 패턴 분석
- 아직 공식 보고되지 않은 부작용 패턴 탐지
- 약물 조합별 부작용 예측
- KAERS 공공 데이터와 자체 데이터 결합

### 4.2 커뮤니티/통계
- 같은 약을 복용한 사람들의 부작용 통계 공개
- 익명 기반 부작용 경험 공유

---

## 5. 기술 스택

| 영역 | 기술 |
|------|------|
| Frontend | Next.js (TypeScript) + Tailwind CSS |
| Backend | ASP.NET Core (C#) |
| OCR | Azure AI Vision 또는 Google Cloud Vision API |
| Database | PostgreSQL |
| 약품 데이터 | 식약처 공공 API, KAERS 공공 데이터 |
| 인증 | JWT (ASP.NET Core Identity) |
| 배포 | Docker + Docker Compose |
| 스토리지 | Azure Blob Storage 또는 AWS S3 (약봉투 이미지) |

---

## 6. 비기능 요구사항

- **모바일 친화적**: PWA 적용, 카메라 직접 접근 지원
- **접근성**: 고령자를 고려한 큰 글자, 직관적 UI
- **개인정보 보호**: 약봉투 이미지는 OCR 처리 후 즉시 삭제 옵션 제공, 의료 데이터 암호화 저장
- **응답 속도**: OCR 처리 5초 이내

---

## 7. 성공 지표 (MVP)

| 지표 | 목표 |
|------|------|
| 부작용 보고 완료율 | OCR 인식 후 보고 완료 비율 70% 이상 |
| OCR 약품명 인식 정확도 | 85% 이상 |
| 사용자 재방문율 | 첫 보고 후 2주 내 재방문 40% 이상 |

---

## 8. 제약 사항

- 본 서비스는 의료 진단 서비스가 아니며, 의학적 조언을 제공하지 않음
- 부작용 보고는 참고용이며 전문 의료진 상담을 권장하는 면책 고지 필요
- 식약처 공공 API 활용 범위 및 데이터 라이선스 확인 필요
